# Default Agentic Architecture & Skills Orchestration

For all development, refactoring, designing, optimization, and auditing tasks across all projects:

1. **Active Skills Inventory & Automatic Dispatch:**
   The agent must automatically consult and apply the following domain-specialized skills based on task context:

   - **UI/UX & Styling:** `ui-ux-pro-max`, `ui-styling`, `design-system`
     * Enforce professional design intelligence, contrast (WCAG 2.1 AA), responsive layouts, 8px grid, smooth micro-interactions, and pre-delivery checks.
   
   - **Database & PostgreSQL / Supabase:** `database-admin`, `database-architect`, `database-optimizer`, `database-design`, `postgres-best-practices`, `postgresql`, `sql-optimization-patterns`, `nextjs-supabase-auth`
     * Enforce index optimization, safe non-blocking migrations, schema integrity, query planning, and Row Level Security (RLS).
   
   - **Frontend & React Performance:** `react-best-practices`, `react-patterns`, `react-state-management`, `web-performance-optimization`, `application-performance-performance-optimization`
     * Enforce memoization, virtualization for large datasets, minimal re-renders, fast bundle loading, and clean state flows.
   
   - **Security & Authorization:** `backend-security-coder`, `frontend-security-coder`, `auth-implementation-patterns`, `api-security-best-practices`, `broken-authentication`, `cc-skill-security-review`
     * Enforce input sanitization, RBAC role validation, secure session handling, and prevention of injection / token leaks.
   
   - **Testing, QA & Debugging:** `playwright-skill`, `api-testing-observability-api-mock`, `debugging-strategies`, `debugger`, `code-review-excellence`, `code-review-checklist`
     * Test logic end-to-end, verify error boundaries, and perform self-review against checklists.
   
   - **Clean Code & Architecture:** `code-refactoring-refactor-clean`, `codebase-cleanup-tech-debt`, `architecture-patterns`, `architect-review`, `api-design-principles`, `api-patterns`
     * Modular design, single responsibility, clean folder separation, and zero dead code.

2. **Always-On Standard:**
   These standards and skills are permanently active as default operational playbooks for all turns and future projects.
